# Protótipos (wireframes textuais)
Layout comum: barra de navegação no topo, conteúdo central (máx. 1000 px), rodapé com aviso educativo.

**Início**
```
[VivaSaúde] Início | Rosa | Azul | Quiz | Histórico | Referências | Tema
Informação confiável para cuidar de você.   [Fazer o quiz]
[Card Outubro Rosa]   [Card Novembro Azul]
Por que conscientizar? / Aviso educativo
```
**Outubro Rosa / Novembro Azul**
```
Título (cor da campanha) + subtítulo + aviso
[Seção] x5-6 · Mitos e verdades (3 cards) · [Testar] [Fontes]
```
**Quiz**
```
Pergunta n de 12 [=====-----]
Enunciado
(A) (B) (C) (D)    [mensagem de erro se vazio]
[Voltar] [Avançar/Finalizar]
```
**Resultado**
```
Resultado  9/12 · 75%   Acertos / Erros   Mensagem
Revisão (resposta, correta, explicação)   [Refazer] [Início] [Histórico]
```
**Histórico**
```
Tabela: Data | Pontuação | Acertos | Questões      [Excluir histórico]
```
Os protótipos visuais finais correspondem às telas do sistema (`index.html`).
